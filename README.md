# SE — Software Testing Lab (Selenium + Python)

Website testing scripts written for the BSc lab exam using Selenium WebDriver with Python.

## What's inside

| Files | What they test |
|-------|----------------|
| `Check Login Form by (ID) and perform logout (LINK_TEXT).py` | Login form + logout flow |
| `E-commerce website test.py` | E-commerce site flow |
| `updated unit testing.py`, `updated integration testing.py`, `updated system testing.py`, `updated acceptance testing.py` | Testing levels |
| `Identify *Locator*.py`, `Perform Search Operation by Basic Locator.py` | Element locators (ID, class, tag, CSS) |
| `Brows Website from Pycharm IDE.py` | Browser launch basics |

## Run

```bash
pip install selenium
python "<file>.py"
```

> Requires Python 3, Selenium and a matching browser WebDriver (ChromeDriver/GeckoDriver).
